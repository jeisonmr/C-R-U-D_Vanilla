# CRUD con TypeScript + Vanilla JavaScript

Aplicación CRUD (Create, Read, Update y Delete) desarrollada con **TypeScript**, **Vanilla JavaScript**, **Vite** y **Tailwind CSS v4**. Este proyecto tiene como objetivo fortalecer los fundamentos del desarrollo web moderno, la manipulación del DOM, el tipado estático y el uso de utilidades CSS sin depender de frameworks.

## 🚀 Tecnologías

* TypeScript
* Vanilla JavaScript
* Vite
* Tailwind CSS v4
* HTML5
* CSS3

## ✨ Características

* Crear, leer, actualizar y eliminar registros.
* Manipulación del DOM con JavaScript puro.
* Interfaz responsiva con Tailwind CSS v4.
* Código tipado con TypeScript.
* Arquitectura simple y fácil de mantener.

## 📦 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```

2. Accede al directorio del proyecto:

```bash
cd tu-repositorio
```

3. Instala las dependencias:

```bash
npm install
```

4. Inicia el servidor de desarrollo:

```bash
npm run dev
```

## 🛠️ Scripts

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Compila para producción
npm run preview  # Previsualiza la compilación
```
